# 前端认证与权限体验检查表

## 会话与导航

- [ ] 登录、刷新、登出、会话初始化和失效路径复用 `useAuthStore` 与请求层。
- [ ] 强制改密、回跳地址和公开路由的守卫行为已覆盖。
- [ ] 无效服务端路由和未知视图路径被拒绝，不进入任意动态导入。
- [ ] 浏览器持久化仅包含现有允许的非敏感字段和显式会话状态。

## 权限与租户体验

- [ ] 权限指令、Hook、路由 `meta.permission` 和 handler 行为一致。
- [ ] `*:*:*`、单权限、权限数组、无权限和权限变化状态已验证。
- [ ] 默认租户、受保护管理员等后端限制在 UI 中正确呈现，但不替代服务端校验。
- [ ] 单条、批量、详情、成员、导入导出和状态操作没有遗漏前端权限体验。

## 安全与测试

- [ ] Token、密码、验证码和重置令牌没有进入 URL、日志或测试输出。
- [ ] 已运行认证 API、Store、守卫、指令或 Hook 的相关回归测试。
