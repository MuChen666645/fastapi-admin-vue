# 前端代码评审检查表

## 契约与状态

- [ ] 调用方经过 API/Parser 和统一请求层，没有绕过传输边界。
- [ ] API 类型、字段、分页、空值、错误与真实后端契约一致。
- [ ] Store 的持久化、失效、租户和会话边界没有泄露或复用错误数据。
- [ ] Loading、禁用、错误、成功、重复提交和 handler 防护行为完整一致。

## 路由、权限与 UI

- [ ] 守卫、动态路由、静态权限、权限指令和操作 handler 没有分歧。
- [ ] 前端限制没有被误作后端授权；默认租户和管理员 UI 限制符合已核验服务端规则。
- [ ] 系统设置未进入 `views/`，内容区 Loading 不受页面高度影响。
- [ ] 功能图标静态导入且图标按钮具有可访问名称；文本、表格、抽屉和移动布局不重叠。

## 安全与交付

- [ ] 没有 `any`、`@ts-ignore`、不安全 HTML、任意 iframe/外链/import 或敏感值泄露。
- [ ] 发现有实际可达路径、影响与复现证据，不将代码风格偏好报告为缺陷。
- [ ] 测试、构建、浏览器、真实 API 与部署验证边界已明确。
