# AppBreadcrumb 使用文档

`AppBreadcrumb` 根据当前路由的 `matched` 链路渲染面包屑。它负责标题翻译、当前项标记、内部路由跳转和安全的外链打开，不请求 API，也不管理菜单权限。

## 基础用法

```vue
<AppBreadcrumb />
```

组件通常由 `BasicLayout` 统一挂载。没有可展示的路由项时，组件不渲染 DOM。

## 路由元数据

面包屑读取以下 `RouteMeta` 字段：

| 字段             | 说明                                               |
| ---------------- | -------------------------------------------------- |
| `title`          | 面包屑标题；静态词典中的标题会按当前语言翻译。     |
| `hideBreadcrumb` | 为 `true` 时隐藏当前路由项。                       |
| `menuType`       | `C` 表示容器或内部路由，`L`、`W` 表示外链。        |
| `link`           | 外链地址，仅接受 `http`/`https` 且不含用户名密码。 |

## 导航行为

- 当前项只读，不会生成跳转链接。
- 内部路由使用 Vue Router 按名称跳转。
- 外链使用新窗口打开，并强制设置 `noopener,noreferrer`。
- 外链地址无效、协议不安全或包含凭据时会被忽略。

组件没有 Props、Events 或暴露方法。标题、权限和路由是否可访问由路由和后端契约决定，不能通过面包屑替代权限校验。
