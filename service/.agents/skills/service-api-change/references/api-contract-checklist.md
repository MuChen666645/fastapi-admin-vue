# API 契约检查表

## 路由和请求

- [ ] 路由完整路径使用当前 `settings.API_V1_PREFIX`，默认是 `/api/v1`。
- [ ] Controller 只声明模块局部前缀，静态路由位于动态路由之前。
- [ ] 方法、路径参数、查询参数、请求体和上传字段与 DTO 一致。
- [ ] 参数使用 `description`，路由使用中文 `summary`。

## 响应和错误

- [ ] 成功响应与现有 `ApiResponseDto`/分页模型一致。
- [ ] JSON、文件、流、HTML 和原始响应正确处理包装跳过机制。
- [ ] 认证失败、无权限、租户不匹配、资源不存在、校验失败和冲突行为与现有语义一致。
- [ ] 不用返回空列表掩盖越权访问。

## 权限和数据

- [ ] 所有敏感读取和写入都有集中认证/权限依赖。
- [ ] 查询使用适用的租户条件、数据范围和资源所有权条件。
- [ ] 单条、批量、导入、重置、关联、导出和后台任务路径已一起检查。
- [ ] 新权限码有对应 seed 和测试。

## 验证

- [ ] 有一个修复前失败、修复后通过的回归测试，或说明为何不适用。
- [ ] 已检查真实前端调用方和契约影响。
- [ ] 已运行目标测试、必要的扩展测试和 `git diff --check`。
