# 授权面检查表

## 身份和会话

- [ ] Authorization Header、JWT 签名、过期时间、缓存状态、用户状态和撤销状态均已检查。
- [ ] 密码修改、Refresh Token、验证码和登录锁定没有绕过既有认证服务。
- [ ] Redis 不可用时的降级有界，安全关键状态不会静默放宽。

## 权限和管理员保护

- [ ] 读取、创建、修改、删除、状态、批量、导入、重置、关联和导出路径均已枚举。
- [ ] 权限码来自集中依赖，管理员角色来自 `settings.ADMIN_ROLE_CODE`。
- [ ] 直接角色字段和关联表角色绑定均已考虑。
- [ ] 单条和批量接口的授权规则一致。

## 租户和数据范围

- [ ] 查询和写入都限制到当前租户。
- [ ] 数据范围覆盖全量、本部门、子部门、自定义部门和本人等适用分支。
- [ ] 部门祖先匹配不会发生数字前缀碰撞。
- [ ] 文件、任务、通知、导出、日志和在线会话有所有权检查。

## 测试

- [ ] 未登录、无权限、跨租户、越过数据范围和受保护管理员均有拒绝测试。
- [ ] 合法操作者、边界部门、撤销会话和重复提交均有行为测试。
- [ ] 不记录 Token、密码、验证码、MFA 或密钥。
