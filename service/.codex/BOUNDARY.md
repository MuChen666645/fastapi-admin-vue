# 后端边界

## 分层边界

- Controller：HTTP 解析、依赖注入、授权声明和响应契约。
- Service：业务校验、事务编排、状态流转、缓存失效和领域错误决策。
- DAO：查询构建和持久化。
- DTO 与 DO 分离：前者用于公开校验，后者用于持久化。

## 安全

- 服务端必须校验每个请求、权限、租户或数据范围关系与状态流转。
- 不记录凭据、Token、密码、验证码、MFA、密钥、重置令牌或完整敏感载荷。
- OIDC、LDAP、SMTP、OSS、Webhook 和数据库操作通过类型化 Settings 与显式校验接入，
  禁止硬编码端点或密钥。
- 使用参数化查询或 ORM 表达式；Header、查询、请求体、文件、重定向和第三方响应均为
  不可信输入。

## 数据库与运维

- 迁移变更需提供设计、影响、回滚、离线 SQL 校验和相关回归测试。
- 未确认环境与目标范围时，不执行破坏性数据库、Redis、容器、备份或远程服务操作。
- 覆盖率、缓存、字节码、日志、本地上传和 IDE 元数据不是源码资产，应保持忽略，不能用
  它们掩盖测试或迁移失败。

## 前后端契约

接口变化时，同步更新 Controller、DTO、Service 行为、测试、前端 API 类型与调用方，
并记录方法、路径、字段、响应、错误、授权、租户语义、幂等和重试。不得产生前端猜测或
后端未说明的契约漂移。
